Seeding fixes. Every lookup now reads the branch the seed writes, so seeding a branch no longer updates nodes on the default branch or wires branch nodes to its peers. Connection and Infrahub SDK errors anywhere in a seed, the first namespace lookup included, are raised as `IntentConnectionError`. A session whose `local_ip` or `remote_ip` no seeded interface carries, or whose `peer_group` is not declared, is an `IntentValidationError` naming the session, where before the field was left out and the device rejected the config at deploy time. A declared peer group that no session uses is logged as a warning. Not yet run against a live Infrahub.
