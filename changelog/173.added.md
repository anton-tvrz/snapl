The dashboard page shows a row of links: Infrahub, the Temporal Web UI and the drift schedule, the GitHub repo, pull requests, Actions and project board, the JSON API, and the quickstart and demo scenarios. The links come from the same settings the server reads, so they point at the stack it describes. `SNAPL_PROJECT_BOARD_URL` sets the board. The links are also served at `GET /api/v1/links`.
