A dashboard snapshot is much smaller: the page gzips its data and base64-encodes it, and the browser unpacks it when the file opens. From the 2026-11-20 archive, a 7-day snapshot is 1.28 MB (was 3.50 MB) and a 30-day one is 1.44 MB (was 5.40 MB). Since the data is no longer readable in the file, `snapl dashboard --snapshot FILE --bundle-json OUT` also writes it to `OUT` as indented JSON to read before publishing. The summary gives the data's unpacked size and says where to read it. A snapshot written before this change still opens. A browser without `DecompressionStream` is told it needs a newer one.
