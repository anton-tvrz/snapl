Orchestrator cleanup. `snapl schedule show` reads the last five runs at the same time, not one after another, and triggering a run no longer reads them at all. The four workflows write audit events through one shared helper (`workflows/audit.py`) with one retry policy and timeout. The per-device audit writes of a remediate run stay one at a time: `snapl audit` lists a run's records in the order they were written, and writing them at once would make that order differ from run to run.
