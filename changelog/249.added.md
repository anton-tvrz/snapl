The dashboard now shows what the loop did over time, not only its latest run (spec 015). From the audit trail, the history API answers four more series when they are named with `series=`: devices in sync and open drifts at each scan, runs by trigger and outcome, and each repaired drift's duration. A new route, `GET /api/v1/drift-summary`, gives each device's drift episodes over a range, how many are still open, its time drifted, and the most paths it had missing and undesired. The page draws them as Fabric history and Drift by device, and the number row's fourth card now counts the runs of the last 24 hours and names the failures. The metrics API has ten more views. Seven read what the worker and the dashboard already exported: mean workflow and gNMI times, workflows completed, activity run time, worker slots in use, Temporal request time, and each dashboard source's read time. Three read counters the worker now records on its existing endpoint: `snapl_scan_results_total` (each scan of a device by what it found), `snapl_drift_paths_total` (differing paths by kind) and `snapl_deploy_ends_total` (each deploy's end by outcome and reason). Their labels come from fixed lists, and recording never fails a scan or a deploy. A new `count` unit leads with its latest point and the window that point covers, never with a sum of points. The designed page puts the metrics in four groups: the loop's timing, what the loop did, the worker, and the dashboard. A scan now records its steps in the audit trail (reading intent, and collecting each device, completed or failed with its reason), so the loop strip shows a scan's blocks, and a drift response's scan and repairs. Every figure the dashboard showed before is unchanged. `invoke history.archive` and `snapl dashboard --snapshot` carry all of it. A snapshot exports the ten new views at a coarser step (3 h over seven days), which a note on each view states, so a seven-day snapshot grows by 46% instead of almost tripling. The counters and the scan steps are checked in tests and on captured fixtures, and have not yet been run against the lab.
