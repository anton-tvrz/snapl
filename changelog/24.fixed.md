First live run against SR Linux 26.3 surfaced three real bugs, all fixed: the executor's `bgp.j2` rendered config the device rejects (missing mandatory `router-id`, no enabled address family, neighbor referencing an undefined peer-group); `apply_batch` raced concurrent exclusive gNMI config sessions against the same device (now serialized per executor instance); and the collector keyed live responses wrong (SR Linux returns empty update paths and module-prefixed paths — now normalized back to the requested paths).
