The audit trail now records which way each drift runs and who started each deploy. A scan's per-device record adds `undesired_paths`, the paths that are on the device but not in intent. A deploy's start record adds `parent_workflow_id`: the reconcile that started it, or `null` for an operator's `snapl deploy`. Both fields are additive, and the spec 010 dashboard reads them to show drift direction and run triggers from history without guessing.
