Dashboard API additions for the designed UI (spec 011): `GET /api/v1/topology` returns the use case's devices and the links their interfaces declare in intent, and `/api/v1/devices` and `/api/v1/runs` accept `at=` to show the state the audit trail recorded up to a past time. `GET /api/v1/drift-timeline` returns one lane of scan points per device and the drift episodes over them, with what repaired each. `GET /api/v1/runs/steps` returns what each NAF block did in one run, as far as the audit trail records it. `GET /api/v1/mode` says whether the server shows the live stack or an archive.
