A metric series' first observation now shows on the dashboard's rate-based views (`gnmi-duration`, `gnmi-errors`, `workflow-duration`, `worker-lag`), so a device's first gNMI error is no longer invisible. `rate()` sees no increase on a series that has just been created; the queries now count a series with no sample one window ago by its value, as long as Prometheus was already scraping the worker then. In the first window after Prometheus starts, a first observation is still missed.
