New `invoke demo.*` tasks take a clean checkout to a demo-ready environment: `demo.seed` provisions the Infrahub schema and seeds the Source of Truth (replacing a copy-paste REPL snippet), `demo.check` preflights the whole stack — Temporal, Infrahub, seeded device count, and a gNMI probe per device — reporting every result before failing, `demo.up` chains deps, lab, seed and check, and `demo.reset` tears it all down for a clean rehearsal. Connection settings resolve from the same env vars and defaults the Temporal worker uses, so a task cannot seed a different Infrahub than the worker queries.
