A second containerlab topology, `containerlab/site_edge.yml`, for the site_edge use case (spec 008): an SR Linux site edge and carrier plus four Linux traffic hosts, on its own management network `clab-snapl-site-edge` (172.20.22.0/24), so it runs beside dcfabric. `invoke dev.lab-deploy`, `dev.lab-destroy` and `demo.up` take `--use-case` (default `dcfabric`); TLS is stripped from gNMI on the routers only. For the live ACL captures: `dev/scripts/site_edge_capture.cli` (the configuration by hand) and `dev/scripts/capture_srlinux_acl_state.py` (collects `/acl` into a fixture, never writing intent or config through snapl).
